# 0.4.0 单机验证记录

日期：2026-11-05（北京时间）。目标硬件、内核与限制见项目 README。

## 已完成

- 观察版、控制版编译与 ad-hoc 签名校验；不是 Apple 签名。
- CPU 身份、独立 operating/efficiency 倍频字段、十核睿频表解码回归。
- 零原生状态不阻止采样、20 CPU 自检、暖机、超时／无效／热状态透传及负载退出后降低请求的测试。
- Linux 6.8 非 HWP 选频整数算法 20,000 组差分，零差异；仅验证算法，不验证跨系统调度等价。
- 固定 kernel / Boot KC 哈希、UUID、函数重定位解释与原生函数体校验。
- x86_64 KEXT、无 SIMD、无直接 WRMSR、无 PM dispatch 重注册、无周期跨核 rendezvous、无 urgency/deadline 钩子的静态检查。
- 控制版在固定目标上实际重启并进入 `Mode=2`、`Status=controlling`，保留 CpuTscSync 1.1.2。

## 运行结果

66 秒的空闲、资格负载、20 线程非 AVX 整数满载、恢复、单线程和再次空闲测试：

- 满载 19 份发布快照覆盖全部 20 个逻辑 CPU；用于计算的样本年龄不超过 250 ms。
- 各逻辑 CPU 满载平均 3190.6–3195.3 MHz，整体平均 3193.4 MHz。
- 每逻辑 CPU 新增 401–580 份满载有效样本。
- 恢复／低负载的新鲜样本最低 1236 MHz，请求最低 12 倍频。
- 11,225 次请求覆盖，11,225 次读回成功，故障与回退均为 0。

频率由 APERF/MPERF、额定 2.9 GHz 和假定 100 MHz BCLK 计算。未将请求值或影子策略计算值当成实际频率；休眠核心遗留的旧样本不纳入低负载结论。

## 未验证与局限

- 仅一台目标机的短时控制测试，不是通用 X99 兼容性承诺。
- 两组性能测试各为单次、不同时间的测量，后台负载未严格控制，不能把全部差异都归因于驱动。
- 没有本轮独立 powermetrics 或墙上功耗测量。
- 没有 Geekbench 全过程逐核频率／功耗记录，也没有同机 Ubuntu 的 Geekbench 7.1.0 对照。
- 长期稳定性、睡眠唤醒、空闲功耗和系统动画帧时间没有完成验收。
- 0.4.0 Observer 构建完成静态验证，未单独进行该版本的运行验收。
